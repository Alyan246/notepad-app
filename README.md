## Download & Installation Guide

Download the appropriate installer for your platform from the [Releases](../../releases) section.

---

### Windows

| Architecture | Recommended Installer | Alternative |
| :--- | :--- | :--- |
| **64-bit (x64)** | `Padore_0.1.0_x64-setup.exe` *(Installer wizard)* | `Padore_0.1.0_x64_en-US.msi` *(MSI package)* |

#### Installation Steps:
1. Download **`Padore_0.1.0_x64-setup.exe`**.
2. Double-click the installer and follow the setup wizard.
> **Note for Windows SmartScreen:** Because this app is self-signed, Windows may display a blue *"Windows protected your PC"* prompt. Click **More info** $\rightarrow$ **Run anyway** to proceed with installation.

---

### macOS

| Processor Type | Recommended Installer | Alternative Archive |
| :--- | :--- | :--- |
| **Apple Silicon (M1/M2/M3/M4)** | `Padore_0.1.0_aarch64.dmg` | `Padore_aarch64.app.tar.gz` |
| **Intel Macs** | `Padore_0.1.0_x64.dmg` | `Padore_x64.app.tar.gz` |

#### Installation Steps:
1. Download the `.dmg` file matching your Mac's processor type.
2. Double-click the `.dmg` file to open it.
3. Drag **Padore** into your **Applications** folder.
> **Note for macOS Gatekeeper:** On first launch, if macOS says *"Padore cannot be opened because it is from an unidentified developer"*, **Right-click (or Control-click)** the app in Applications, select **Open**, and click **Open** again in the confirmation dialog.

---

### Linux

| Distribution / Format | Target File | Recommended Command / Method |
| :--- | :--- | :--- |
| **Universal (Arch, Fedora, etc.)** | `Padore_0.1.0_amd64.AppImage` | Portable binary (Make executable and run) |
| **Ubuntu / Debian** | `Padore_0.1.0_amd64.deb` | `sudo apt install ./Padore_0.1.0_amd64.deb` |
| **Fedora / RHEL / openSUSE** | `Padore-0.1.0-1.x86_64.rpm` | `sudo dnf install ./Padore-0.1.0-1.x86_64.rpm` |
